# Cross-Market Macro Dashboard

An AI-powered analytics platform tracking 8 global markets in real time, with cross-asset correlation analysis and natural-language market commentary.

## Live Demo
🔗 [Try it here](https://yidatong-macro-dashboard.streamlit.app) *(coming soon)*

## Tech Stack
- **Python · Streamlit · Plotly**
- **yfinance** for market data
- **Anthropic Claude API** for AI commentary

## Features
- Real-time price tracking across US equities, Chinese stocks, commodities, and crypto
- Normalized cross-asset performance comparison
- Daily return correlation matrix
- AI-generated market narrative (powered by Claude)
